# Contributor Code of Conduct

## General policy

As contributors and maintainers of this project, we pledge to respect all people who contribute through reporting issues, posting feature requests, updating documentation, submitting pull requests or patches, and other activities.

We are committed to making participation in this project a harassment-free experience for everyone. Project maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, wiki edits, issues, and other contributions that are not aligned to this Code of Conduct.

## Respect the no-AI policy

This addon is published to the Godot Asset Store and (soon, if not already) to itch.io, which both require an AI disclosure. This addon is also originally being made for [Wheel Steal Game](https://wheelstealgame.com/), which does not use AI at all. At the time this policy was published (Nov 15, 2026) the authors had never used AI to make this addon or any resources, and no contributor had explicitly mentioned AI in PR descriptions.

We adopt Godot's own policy level of AI contributions, as published on June 30th 2026 - [announced here](https://godotengine.org/article/contribution-policy-2026/), the full policy [is here](https://contributing.godotengine.org/en/latest/development/contribution_rules.html#ai-assisted-contributions).

### AI contributions policy

In case it changes, we have copied the relevant parts from the policy:

- No autonomous AI agent use or vibe coding
- Do not use AI to generate substantial pieces of code
  - AI should not be used to author code. Code authoring is more than typing, it includes making decisions about where the code should go, what techniques/algorithms should be used, and ultimately what the code should look like. All those decisions need to be made by a human.
  - For example using AI for code completion is permissible. The important consideration is whether the AI is producing the same code you would have written manually or not. If you do not have the knowledge/ability to write the code yourself, you are not allowed to use AI to write it.
  - You must understand and take responsibility for everything that you submit.
  - If you do use AI in some capacity to author code, you must disclose it in the PR discussion.
- No AI-generated text in human-to-human communication
  - Modified here: Use for direct translations is allowed, please hand write your original message
- Adapted: All PRs will continue to always be reviewed by the core team before merging
- Do not use AI agents to submit PRs on your behalf
- Do not use AI to generate user-facing media (e.g. documentation, images and audio)

Beyond this, the goal is such that: Any user should be able to safely publish a game with using this addon without needing to check the AI disclosure. If you are ok with the AI policy level of AI in Godot itself, then you should be ok with this addon.

### If you already made improvements via AI

While AI-generative pull requests cannot be merged, if you do end up (accidentally) opening one anyways, you may be directed to collaborate with someone in the road generator community maintaining one or another fork which allows AI.

In our community, you may still discuss, collaborate, and coordinate via our discord with other community members. The broader community goal is to be inclusive and supportive for game devs, and we acknowledge that different developers may different personal thresholds for what is "too much AI" or perspectives on using AI for their own projects, even if the core repo here takes a stricter stance.

If you fork the project because you want or need to add AI generated changes for your use case, we still encourage you to share back your efforts in the discord community channel.
