# Contributor Code of Conduct

## General policy

As contributors and maintainers of this project, we pledge to respect all people who contribute through reporting issues, posting feature requests, updating documentation, submitting pull requests or patches, and other activities.

We are committed to making participation in this project a harassment-free experience for everyone. Project maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, wiki edits, issues, and other contributions that are not aligned to this Code of Conduct.

## Respect the no-AI policy

Users of this addon should be confident in publishing a game without needing to tick the AI disclosure box.

This addon is published to the Godot Asset Store, which itself requests publishers to disclose if "This asset uses AI generated assets and/or code". This addon intentionally has no disclosure about AI included (or if so, only temporarily while any such contributions are being removed). The owners of this addon are also committed to publish games that will claim with unambiguous confidence that AI was not used in any form for the production of the game itself, inclusive of this addon. At the time this policy was published (Nov 21, 2026) the owners had never used AI to make this addon or any resources, and no contributor had explicitly mentioned AI in PR descriptions or had LLM co-authored commits.

We adopt Godot's own policy around AI contributions, as published on June 30th 2026 - [announced here](https://godotengine.org/article/contribution-policy-2026/), the full policy [is here](https://contributing.godotengine.org/en/latest/development/contribution_rules.html#ai-assisted-contributions).

If any pull requests are submitted and later found or disclosed as including AI in violation of the described policy, the owners will either revert those changes or seek to have them rewritten.

This policy does not apply to thirdparty libraries which the addon relies on.


### AI/LLM contributions policy

In case it changes, we have copied the relevant parts from Godot's own policy:

- No autonomous AI agent use or vibe coding
- Do not use AI to generate substantial pieces of code
  - AI should not be used to author code. Code authoring is more than typing, it includes making decisions about where the code should go, what techniques/algorithms should be used, and ultimately what the code should look like. All those decisions need to be made by a human.
  - For example using AI for code completion is permissible. The important consideration is whether the AI is producing the same code you would have written manually or not. If you do not have the knowledge/ability to write the code yourself, you are not allowed to use AI to write it.
  - You must understand and take responsibility for everything that you submit.
- Do not allow an AI agent to submit PRs on your behalf
- Do not use AI-generated text in human-to-human communication
  - Machine translations are still acceptable as long as the original content was written by a human.

In addition to these points, we add:

- The owners themselves have committed zero AI code, and seek to prevent others from contributing AI code and assets
- All PRs will continue to be hand-reviewed and analyzed by the owners before merging
  - If owners do not feel equipped to maintain the contributed code, it will be rejected regardless of usage of AI
- Do not use AI to generate assets (e.g. documentation, images, 3D models)
- Any PRs with LLM co-authored commits will be rejected

### If you already made improvements via AI

While AI-generative pull requests cannot be merged, if you do end up (accidentally) opening one anyways, you may be directed to collaborate with someone in the road generator community maintaining a fork which allows AI. We will not officially endorse any single fork as official, but we are happy to direct others.

In our community including on discord, you may still discuss, collaborate, and coordinate with other community members. The broader community goal is to be inclusive and supportive for game devs, and we acknowledge there are different stances on this subject. We believe by making a strict stance for the core addon itself means that anyone can use the repository with confidence, whether they choose to use AI/LLMs in there own project or not.

This policy may be revisited if abused or quality of discussions decline.
